# Magpienest 0.1.1

Tags and ratings on folders, a hover preview, smoother comic reading in the web interface, and two small fixes.

## How to update

- Download `Magpienest-0.1.1-win-x64.zip` and unzip it over your current Magpienest folder (or unzip it somewhere new and copy your `data\` folder into it). Your library, settings and installed plugins stay as they are.
- The library database is upgraded the first time 0.1.1 starts.
- If you use the web interface, open Settings, Plugin store and press "Update" on Web interface to get the new web features. Videos, games and the image window have no update this time.

## What is new

### Tags and ratings on folders

- Right-click a folder in the folder tree and choose "Folder tags and rating…".
- A folder's tags count for everything in it and in its subfolders: tag filters, search and the tag counts include those items. Tags add up down the tree.
- A folder's rating counts for the items inside that have no rating of their own, in the rating filter and the rating sort. The nearest rated folder wins.
- Labelled folders show a star with their rating and a tag mark in the tree; the details panel shows what an item gets from its folders.
- The web interface's filters work the same way, and its item details show folder tags too.

### Hover preview (new built-in plugin)

- Rest the mouse on an illustration or a comic in the library and it shows large beside the cursor, never under it and never enlarged. On a comic, the wheel turns the pages. Moving away or clicking closes it.
- The delay can be set in Settings (0.2 to 1 second; 0.4 by default), and the plugin can be switched off in Settings, Plugins.
- The web interface does the same with a mouse.

### Web comic reader

- Strip mode as in the app: all pages in one continuous row, scrolled smoothly by the wheel, keys, mouse drag or touch. The "pages shown" button (or D) cycles one page, two pages and strip, and the choice is saved with the book.
- In one-page and two-page modes every wheel notch now turns a page at once; the next pages are loaded ahead, so there is no blank flash.

### Fixes

- The collapsed navigation rail now shows its icons whole.
- Traditional Chinese: the About page's data folder line now reads 「資料存放位置」.

## Known limitations

- Folder tags and ratings are tied to the folder's path: renaming or moving a folder outside Magpienest loses them (the items' own tags and ratings are kept).
- Folder tags and ratings can be edited in the app only, not yet in the web interface.
- If you go back to 0.1.0 after using 0.1.1, editing tags there can drop tags that only folders carry.
- The limitations of 0.1.0 still apply (placeholder icon, unsigned exe, Windows 10/11 x64 only).

# Magpienest 0.1.1（繁體中文）

資料夾可以加標籤和評分、新增懸浮檢視、網頁介面看漫畫更順，另外修正兩個小問題。

## 如何更新

- 下載 `Magpienest-0.1.1-win-x64.zip`，直接解壓縮覆蓋你現在的鵲藏資料夾（或解壓縮到新位置，再把舊的 `data\` 資料夾複製過去）。收藏庫、設定和已安裝的插件都會保留。
- 第一次啟動 0.1.1 時，收藏庫資料庫會自動升級。
- 有用網頁介面的話，到「設定」→「插件商店」，在「網頁介面」上按「更新」，就能用到網頁的新功能。影片、遊戲和圖片視窗這次沒有更新。

## 新功能

### 資料夾標籤與評分

- 在資料夾樹的資料夾上按右鍵，選「資料夾標籤與評分…」。
- 資料夾的標籤會套用到資料夾和子資料夾裡的所有項目：用標籤篩選、搜尋和標籤數量都會把這些項目算進去。上層和下層資料夾的標籤會疊加。
- 項目自己沒有評分時，評分篩選和依評分排序會用資料夾的評分，以最近一層有評分的資料夾為準。
- 加過標籤或評分的資料夾，在資料夾樹上會顯示星星和評分、標籤記號；詳細資料會顯示項目從資料夾得到的標籤和評分。
- 網頁介面的篩選效果一樣，項目詳細資料也會顯示資料夾的標籤。

### 懸浮檢視（新的內建插件）

- 滑鼠停在收藏庫裡的插畫或漫畫上，圖片會在游標旁放大顯示：不會擋到游標，也不會把小圖放大。在漫畫上捲動滾輪可以翻頁。滑鼠移開或按一下就會關閉。
- 可以在「設定」調整要停多久才顯示（0.2 到 1 秒，預設 0.4 秒），也能在「設定」→「插件」關掉這個插件。
- 網頁介面用滑鼠時也一樣。

### 網頁漫畫閱讀器

- 和程式一樣的長條模式：所有頁面接成一長條，用滾輪、按鍵、滑鼠拖曳或手指滑動順順地捲。「顯示頁數」按鈕（或按 D）會在單頁、雙頁、長條之間切換，選擇會存回這本書。
- 單頁和雙頁模式下，滾輪每轉一格就立刻翻一頁；後面的頁面會預先載入，翻頁時不會閃黑畫面。

### 修正

- 側邊欄收起時，圖示會完整顯示。
- 「關於」頁的資料夾那一行改成「資料存放位置」。

## 已知限制

- 資料夾的標籤和評分是跟著資料夾位置記的：在鵲藏外面把資料夾改名或搬走，這些標籤和評分會不見（項目自己的標籤和評分不受影響）。
- 資料夾的標籤和評分目前只能在程式裡編輯，網頁介面還不能。
- 用過 0.1.1 之後如果換回 0.1.0，在 0.1.0 裡編輯標籤時，可能會清掉只有資料夾在用的標籤。
- 0.1.0 的已知限制仍然存在（暫時的圖示、執行檔沒有簽章、只支援 Windows 10/11 x64）。
