# Magpienest 0.1.0

The first release of Magpienest (鵲藏), a Windows collection library for your local illustrations, comics, videos and games. Every feature is a plugin that can be switched on or off in Settings. Your files are never moved, renamed or changed: the library is only an index.

Download `Magpienest-0.1.0-win-x64.zip`, unzip it anywhere you can write to and run `Magpienest.exe`. Windows 10/11 x64; nothing to install. The zip holds the library, illustrations and comics; videos, games, the image window and the web interface are added from the plugin store inside the app (Settings, Plugin store).

## What is in this release

### Library and browsing

- Add folders; Magpienest scans them and keeps the library up to date (optionally at every start).
- Thumbnail wall with a folder tree, search by title and tag, sorting (title, path, date added, last opened, rating, file date, file size, time spent, progress), filters (favourites, minimum rating, status, tags) and an adjustable tile size.
- Tags, ratings, favourites, status (in progress, completed, on hold, dropped, planned) and notes, also for several selected items at once.
- A details panel, "Show in Explorer", and removing items from the library without touching the files.
- Missing files are marked and can be cleaned up from Settings. The thumbnail cache can be cleared from Settings.

### Illustrations

- Decodes JPEG, PNG, GIF, BMP, TIFF, ICO, WebP, HEIC/HEIF, AVIF, JPEG XL and JPEG XR through Windows codecs (some formats need the matching Windows codec or extension).
- Full-window viewer: zoom, rotate, actual size, EXIF orientation, preloading of neighbouring pictures, a bottom bar, and the whole folder as the page list.

### Comics and the book viewer

- A folder of pages, or a zip / cbz / rar / cbr / 7z / cb7 archive, is one book.
- Two-page spreads that follow reading direction (right-to-left or left-to-right), wide pages shown alone, cover shown alone, with defaults in Settings and overrides per book.
- Strip mode: pages scroll continuously in one column; choose between one page, two pages and strip with the "pages shown" button.
- Remembers where you stopped, and tracks status and reading time.
- Natural sorting of page names (2 comes before 10).

### Plugin store

- Settings, Plugin store lists the optional features with their size. "Install" downloads a feature from GitHub, checks its size and checksum, and turns it on; "Update" appears when a newer version exists.
- With "Check for plugin updates at startup" on, a red dot on Settings tells you an update is waiting.

### Videos (plugin store)

- Plays most formats (mp4, mkv, webm, avi, mov, wmv, flv, mpeg, ts and more) with LibVLC.
- Thumbnails and durations on the wall; progress bars and "Mark as watched / unwatched" and "Play from the beginning" commands.
- Each video opens in a frameless player window with hover-only controls: seek bar, volume (up to 200 %), speed, audio and subtitle track menus, fullscreen with a double click, next/previous through the videos shown on the wall.
- "Remember where I stopped" (on by default) resumes each video where you left it.

### Games (plugin store)

- Add a game by its exe or a shortcut, or scan a folder of game folders: Magpienest picks the main program of each folder and skips installers and helpers.
- One-click launch, play time and number of launches, "Running" shown while the game is on, cover images from a file.

### Image window (plugin store)

- Right-click a picture in the viewer or on the illustration wall to open it in a borderless image window: drag to move, resize with the aspect ratio kept, close button on hover.

### Web interface (plugin store)

- Browse your library from a phone, a tablet or another computer in a web browser: illustrations, comics, videos and games, with search and sorting.
- Choose who can connect: only this computer, also devices on your home network (sign in with a QR code or the address), or also from the internet.
- Password sign-in with limits on wrong attempts, and HTTPS with an automatic or your own certificate.
- A "Web" page inside Magpienest shows the web interface in the app.

### Plugins and safe mode

- Settings, Plugins: one card per feature; switch it on or off with immediate effect, remove what you installed, install a plugin from a zip or a folder (with a confirmation that shows name, version and author), and "Restart now" when a restart is needed.
- `Magpienest.exe --safe-mode` loads only the built-in plugins, so a broken plugin can be removed.
- A [developer guide](https://github.com/ddd000987/Magpienest/blob/main/docs/plugin-development.md) and a [sample plugin](https://github.com/ddd000987/Magpienest/tree/main/samples/HelloPlugin) show how to write your own.

### Languages and themes

- English and Traditional Chinese (繁體中文), switched live; the default follows Windows and falls back to English.
- Light, dark and "follow Windows" themes.

### Portable zip

- Self-contained: no .NET installation needed. All data, including the plugins you install, lives in `data\` next to the exe, so copying the folder moves everything.

## Known limitations

- The app icon is a simple placeholder.
- When a video reaches its end the picture turns black instead of staying on the last frame. The controls stay available and Play starts the video again.
- The exe is not code-signed, so Windows SmartScreen may show a warning the first time you run it.
- Windows 10/11 x64 only.
- Some image formats (for example HEIC, AVIF, JPEG XL) depend on codecs that Windows may not have installed.
- The plugin store needs an internet connection to GitHub.

Third-party components and their licences are listed in [THIRD-PARTY-NOTICES.md](https://github.com/ddd000987/Magpienest/blob/main/THIRD-PARTY-NOTICES.md).

# Magpienest 0.1.0（繁體中文）

Magpienest（鵲藏）的第一個版本：Windows 桌面上的收藏庫，用來整理你電腦裡的本機插畫、漫畫、影片與遊戲。所有功能都是插件，可以在「設定」裡開啟或關閉。永遠不會移動、改名或修改你的檔案：收藏庫只是一份索引。

下載 `Magpienest-0.1.0-win-x64.zip`，解壓縮到你有寫入權限的任何資料夾，執行 `Magpienest.exe` 即可。支援 Windows 10/11 x64，不需要安裝。zip 裡包含收藏庫、插畫與漫畫；影片、遊戲、圖片視窗與網頁介面請在程式裡的插件商店加入（「設定」→「插件商店」）。

## 這個版本有什麼

### 收藏庫與瀏覽

- 加入資料夾後，Magpienest 會掃描並保持收藏庫更新（可選擇每次啟動時掃描）。
- 縮圖牆搭配資料夾樹，可依標題與標籤搜尋，可排序（標題、路徑、加入日期、最近開啟、評分、檔案日期、檔案大小、花費時間、進度），可篩選（我的最愛、最低評分、狀態、標籤），縮圖大小可調整。
- 標籤、評分、我的最愛、狀態（進行中、已完成、擱置、放棄、計畫中）與備註，也能一次套用到多個選取的項目。
- 詳細資料面板、「在檔案總管中顯示」，以及從收藏庫移除項目而不動到檔案。
- 找不到的檔案會被標示出來，可在設定中清理；縮圖快取也能在設定中清除。

### 插畫

- 透過 Windows 編解碼器讀取 JPEG、PNG、GIF、BMP、TIFF、ICO、WebP、HEIC/HEIF、AVIF、JPEG XL 與 JPEG XR（部分格式需要 Windows 已安裝對應的編解碼器或延伸模組）。
- 全視窗檢視器：縮放、旋轉、原始大小、EXIF 方向、預先載入相鄰圖片、底部工具列，並以整個資料夾作為翻頁清單。

### 漫畫與書本檢視

- 一個放著頁面的資料夾，或一個 zip / cbz / rar / cbr / 7z / cb7 壓縮檔，就是一本書。
- 雙頁並排會依閱讀方向（由右至左或由左至右）排列，寬頁單獨顯示、封面單獨顯示；預設值在設定中調整，也可以針對每一本書個別覆寫。
- 長條模式：頁面在單一欄位中連續捲動；用「顯示頁數」按鈕在單頁、雙頁與長條之間切換。
- 記住你讀到哪裡，並記錄狀態與閱讀時間。
- 頁面檔名依自然順序排序（2 排在 10 前面）。

### 插件商店

- 「設定」→「插件商店」列出可選用的功能與大小。按「安裝」會從 GitHub 下載、檢查大小與檢查碼，然後開啟；有新版時會出現「更新」。
- 開啟「啟動時檢查插件更新」後，有更新時「設定」上會出現紅點。

### 影片（插件商店）

- 用 LibVLC 播放大部分格式（mp4、mkv、webm、avi、mov、wmv、flv、mpeg、ts 等）。
- 縮圖牆顯示縮圖與片長，並有進度條，以及「標示為已看／未看」和「從頭播放」指令。
- 每部影片在各自的無邊框播放視窗中開啟，控制列只在滑鼠移上去時出現：拖曳列、音量（最高 200%）、速度、音軌與字幕選單，雙擊切換全螢幕，並可切換到牆上顯示的上一部／下一部影片。
- 「記住上次停下的位置」（預設開啟），下次播放時從你離開的地方繼續。

### 遊戲（插件商店）

- 指定 exe 或捷徑來新增，也可以掃描整個遊戲資料夾：Magpienest 會為每個資料夾挑出主程式，並略過安裝程式與輔助程式。
- 一鍵啟動、記錄遊玩時間與啟動次數、遊戲執行中會顯示「執行中」，封面圖片可從檔案設定。

### 圖片視窗（插件商店）

- 在檢視器或插畫牆的圖片上按右鍵，可用無邊框的圖片視窗開啟：拖曳移動、維持比例縮放，滑鼠移上去時顯示關閉按鈕。

### 網頁介面（插件商店）

- 用手機、平板或另一台電腦的瀏覽器瀏覽你的收藏庫：插畫、漫畫、影片與遊戲，可搜尋與排序。
- 選擇誰能連線：只有這台電腦、加上家裡網路的裝置（掃 QR code 或輸入網址登入），或也允許從網際網路連線。
- 密碼登入並限制連續輸錯的次數，支援 HTTPS（自動產生的憑證或你自己的憑證）。
- 鵲藏裡的「網頁」頁面可以直接在程式中開啟網頁介面。

### 插件與安全模式

- 「設定」→「插件」：每個功能一張卡片；用開關立即開啟或關閉，移除你安裝的功能，從 zip 或資料夾安裝插件（安裝前會顯示名稱、版本與作者讓你確認），需要重新啟動時提供「立即重新啟動」。
- `Magpienest.exe --safe-mode` 只載入內建插件，方便移除有問題的插件。
- [開發指南](https://github.com/ddd000987/Magpienest/blob/main/docs/plugin-development.md)與[範例插件](https://github.com/ddd000987/Magpienest/tree/main/samples/HelloPlugin)說明如何開發自己的插件。

### 語言與主題

- English 與繁體中文，即時切換；預設跟隨 Windows，偵測不到時使用英文。
- 淺色、深色與「跟隨 Windows」主題。

### 免安裝 zip

- 自包含：不需要另外安裝 .NET。所有資料（包括你安裝的插件）都放在 exe 旁邊的 `data\` 資料夾，複製整個資料夾就能搬移全部內容。

## 已知限制

- 應用程式圖示目前只是暫時的占位圖示。
- 影片播放到結尾時，畫面會變成全黑，而不是停在最後一格。控制列仍然可用，按播放會從頭再播一次。
- 執行檔沒有程式碼簽章，所以第一次執行時 Windows SmartScreen 可能會顯示警告。
- 只支援 Windows 10/11 x64。
- 部分圖片格式（例如 HEIC、AVIF、JPEG XL）需要 Windows 已安裝對應的編解碼器。
- 插件商店需要能連上 GitHub 的網路。

第三方元件與其授權列於 [THIRD-PARTY-NOTICES.md](https://github.com/ddd000987/Magpienest/blob/main/THIRD-PARTY-NOTICES.md)。
