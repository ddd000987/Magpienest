# Magpienest 0.1.2

Magpienest can now update itself, each folder remembers its own sort, and two folder-tree problems are fixed.

## How to update

- This time, download `Magpienest-0.1.2-win-x64.zip` and unzip it over your current Magpienest folder (or unzip it somewhere new and copy your `data\` folder into it). Your library, settings and installed plugins stay as they are.
- From 0.1.2 on you do not need to do this any more: Magpienest tells you when a new version is out and updates itself when you press "Update".
- The plugins in the plugin store have no update this time.

## What is new

### Updates from inside Magpienest

- At start-up Magpienest checks whether a new version is out. Nothing is downloaded yet: a message with an "Update" button appears, the plugin store shows the new version at the top with its release notes, and Settings gets a red dot.
- Press "Update" and Magpienest downloads the new version, checks its size and checksum, closes, replaces its program files and opens again. The `data\` folder (library, settings, plugins) is never touched.
- If the update cannot finish, Magpienest puts the previous version back and tells you. When Magpienest is in a folder it cannot write to (such as Program Files), it asks you to update by hand.
- The check can be switched off in Settings, Plugin store ("Check for Magpienest and plugin updates at start-up"); it is on by default.

### Sort remembered per folder

- Change the sort (or its direction) while a folder is selected and that folder keeps it; going back to the folder brings it back.
- A folder you never changed uses the sort of the nearest folder above it, else the one of "All".

### Folder tree

- The folder pane can be made wider or narrower by dragging its right edge; the width is remembered.

### Fixes

- After opening a picture and closing the viewer, the grid could show the pictures of every folder while the tree still showed the folder you were in. The grid now stays on that folder.
- Long folder names no longer push the folder tree out of view; they are cut with "…" and the tooltip shows the whole path.

## Known limitations

- Updating from inside Magpienest works from 0.1.2 on; this update to 0.1.2 is done by hand.
- The web interface keeps one sort for everything; per-folder sorts are in the app only.
- The limitations of 0.1.1 still apply (folder tags and ratings follow the folder's path; placeholder icon, unsigned exe, Windows 10/11 x64 only).

# Magpienest 0.1.2（繁體中文）

鵲藏現在可以自己更新，每個資料夾會記住自己的排序，另外修正了資料夾樹的兩個問題。

## 如何更新

- 這一次請下載 `Magpienest-0.1.2-win-x64.zip`，直接解壓縮覆蓋你現在的鵲藏資料夾（或解壓縮到新位置，再把舊的 `data\` 資料夾複製過去）。收藏庫、設定和已安裝的插件都會保留。
- 從 0.1.2 開始就不用再這樣做了：有新版時鵲藏會通知你，按下「更新」就會自己更新。
- 插件商店裡的插件這次沒有更新。

## 新功能

### 在鵲藏裡直接更新

- 啟動時鵲藏會檢查有沒有新版。這時還不會下載：畫面上會出現一則附「更新」按鈕的訊息，插件商店最上方會顯示新版和版本說明，「設定」上也會出現小紅點。
- 按下「更新」後，鵲藏會下載新版、檢查大小和檢查碼，接著關閉、替換程式檔案，再重新開啟。`data\` 資料夾（收藏庫、設定、插件）完全不會動到。
- 如果更新沒辦法完成，鵲藏會還原成原本的版本並告訴你。鵲藏放在不能寫入的資料夾（例如 Program Files）時，會請你手動更新。
- 可以在「設定」→「插件商店」關掉檢查（「啟動時檢查鵲藏和插件的更新」），預設是開啟的。

### 每個資料夾記住自己的排序

- 選著某個資料夾時改排序方式（或遞增、遞減），就只記在那個資料夾；下次點回去會自動換回來。
- 沒改過的資料夾，用上一層最近一個改過的資料夾的排序；都沒有的話，用「全部」的排序。

### 資料夾樹

- 拖曳資料夾欄位的右邊緣可以調整寬度，程式會記住。

### 修正

- 打開圖片再關掉檢視器後，資料夾樹上還亮著原本的資料夾，下面卻顯示所有資料夾的圖片。現在會維持在原本的資料夾。
- 資料夾名稱很長時，資料夾樹不會再跑到畫面外；名稱會用「…」截斷，滑鼠停在上面會顯示完整路徑。

## 已知限制

- 從鵲藏裡直接更新要從 0.1.2 開始才有，這次更新到 0.1.2 仍然要手動。
- 網頁介面所有資料夾共用同一種排序；每個資料夾各自的排序只在程式裡有。
- 0.1.1 的已知限制仍然存在（資料夾標籤和評分跟著資料夾位置記、暫時的圖示、執行檔沒有簽章、只支援 Windows 10/11 x64）。
